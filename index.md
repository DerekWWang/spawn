# Spawn

This is the human reference for the mod: a survival simulation in which players, bots and enrolled villagers share one body, one set of skills and one set of physical rules, and in which everything from a clay jar to a mainframe has to be made the way it really was.

These pages are written for people. They live on their own branch, apart from the code that agents in the world are given, so those agents learn the rules by living under them.

## Conventions used on these pages

- Commands are written as typed. Almost every `/survival ...` command also exists as `/survival control <actor> ...` for an operator directing another actor.
- "Ticks" are game ticks: 20 to the second, 1,000 to the hour of the game clock, 24,000 to the day.
- Default values are given. Server owners can retune many of them by data pack or config; where that is so, the page says it.
