# Spawn

Spawn is a NeoForge mod for Minecraft 26.3. It replaces the game's shortcuts with the
real thing: bodies that need food, water, warmth and company; weather that falls where
the land puts it; ore that weighs what a cubic metre of ground weighs; and a tech tree
in which a computer cannot be built by a society that has not first built steam,
electricity and a cleanroom.

Players, bots and script-controlled people all live under the same rules.

## The units

One item of metal, mineral or chemical is a kilogram. A sack of coal is 25 kg. A liquid
item is a litre, a wire item is a metre, and a block is a cubic metre. One game hour is
1,000 ticks and a day is 24,000. Work is rated in man-hours.
